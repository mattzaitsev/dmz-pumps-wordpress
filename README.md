# DMZ Pumps WordPress Theme

Custom WooCommerce theme for DMZ Pumps.

## Live server installation
Clone this repository into WordPress:

```bash
cd /var/www/html/wp-content/themes
sudo git clone https://github.com/mattzaitsev/dmz-pumps-wordpress.git dmz-pumps
sudo chown -R www-data:www-data dmz-pumps
```

Activate **DMZ Pumps** in WordPress under Appearance → Themes.

## Updating
After future changes are pushed to GitHub:

```bash
cd /var/www/html/wp-content/themes/dmz-pumps
sudo git pull
```

WooCommerce should remain installed and active.
